# ATCB Oficial - Sitio Web

Sitio web para @AtcbOficial (Luis Bonilla) - Refrigeración Comercial e Industrial.

## Cómo usar

1. Sube toda la carpeta a un repositorio de GitHub.
2. Activa GitHub Pages (Settings → Pages → Branch: main / root).
3. Abre el sitio.

## Características

- Modo oscuro + azules de refrigeración
- 100% responsive (escritorio + móvil)
- Animaciones suaves
- Catálogo con categorías y carrito
- Envío de pedidos por WhatsApp
- Panel Admin oculto (clic en el punto del footer)

## Admin

- Clave por defecto: `atcb2024`
- Cambia la clave desde el panel
- Edita historia, galería, productos, contactos
- Las imágenes se guardan en localStorage (base64)

## Archivos

- `index.html` - Página principal
- `style.css` - Estilos
- `script.js` - Lógica
- `data.js` - Datos iniciales
- `images/` - Logo, foto y banner

Datos y carrito se guardan en el navegador (localStorage).
